`java_to_bedrock.tsv.gz` maps Java Edition block states to Bedrock ones for `.litematic` conversion.

It is generated by `tools/make_block_map.py` from [PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data)
(`data/bedrock/1.26.30/blocksJ2B.json` and `blockStates.json`, commit `201ca80`). minecraft-data is
MIT licensed, as stated in its README (the repository has no separate license file).
